# APL121 — Бие даалт №1: Code Quest
## Сэдэв №14: Автобусны карт

### Төслийн зорилго
Долоо хоногийн автобусны картын зардал, үлдэгдэл болон цэнэглэх шаардлагатай анхны өдрийг тооцно.

### Өөрөө тогтоосон сургалтын дүрэм
- Эхний үлдэгдэл: 0–100000₮
- Өдөрт суулт: 0–20
- Эхний суулт: 1000₮
- Дараагийн суулт бүр: 500₮
- 0 суулт: 0₮
- Тухайн өдрийн зардалд мөнгө хүрэхгүй бол тэр өдрийн төлбөрийг хийхгүй, үлдэгдлийг хэвээр үлдээнэ.
- Энэ нь сургалтын зориулалттай тариф, бодит тариф биш.

### Файлууд
- `main.c` — C программ
- `pseudocode.md` — псевдокод
- `tests.md` — тестийн өгөгдөл, хүлээгдэх үр дүн
- `quest_hylbar.fprg` — Flowgorithm-ийн хялбар хувилбар (төслийн үндсэн bd1 хавтаст нэмж хуулна)
- `quest_hylbar_tailbar.txt` — Flowgorithm тайлбар

### GCC-оор компайл ба ажиллуулах
Windows terminal / VS Code Terminal дээр `bd1` хавтаст:
```bash
gcc main.c -o main
.\main.exe
```
### Жишээ
Эхний үлдэгдэл `10000`, өдрийн суултууд `2 3 1 4 2 3 1`.
Тооцоолол: өдөр 1–5 төлөгдөнө; өдөр 6-д мөнгө хүрэхгүй; өдөр 7-д 1000₮ төлөгдөнө.
Нийт төлбөр 9500₮, эцсийн үлдэгдэл 500₮, цэнэглэх шаардлагатай анхны өдөр 6.

### Git эхлүүлэх (репозитор аль хэдийн байгаа гэж үзэв)
Репозиторийн үндсэн хавтаснаас:
```bash
git status
mkdir bd1
```
Файлуудаа `bd1` хавтаст байрлуулаад:
```bash
git add bd1/
git commit -m "BD1: add bus card C program and tests"
git push
```
Өмнөх commit-ууд байхгүй бол тус тусдаа утгатай дор хаяж 3 commit хийнэ:
1. `add pseudocode and project rules`
2. `add C implementation`
3. `add tests and README`
