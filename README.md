# APL121 — Бие даалт №1: Code Quest
## Сэдэв №14: Автобусны карт

### Төслийн зорилго
Долоо хоногийн автобусны картын зардал, үлдэгдэл болон цэнэглэх шаардлагатай анхны өдрийг тооцно.

### Өөрөө тогтоосон сургалтын дүрэм
- Эхний үлдэгдэл: 0–100000₮
- Өдөрт суулт: 0–20
- Эхний суулт: 1000₮
- Дараагийн суулт бүр: 500₮
- 0 суулт: 0₮
- Тухайн өдрийн зардалд мөнгө хүрэхгүй бол тэр өдрийн төлбөрийг хийхгүй, үлдэгдлийг хэвээр үлдээнэ.
- Энэ нь сургалтын зориулалттай тариф, бодит тариф биш.
### Жишээ
Эхний үлдэгдэл `10000`, өдрийн суултууд `2 3 1 4 2 3 1`.
Тооцоолол: өдөр 1–5 төлөгдөнө; өдөр 6-д мөнгө хүрэхгүй; өдөр 7-д 1000₮ төлөгдөнө.
Нийт төлбөр 9500₮, эцсийн үлдэгдэл 500₮, цэнэглэх шаардлагатай анхны өдөр 6.
